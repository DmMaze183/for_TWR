# О проекте

Код компонента опубликован для доклада на TWD'3

> Любое изменение, использование и копирование приветствуется и поощряется.

# Что он делает 

Раскрывающийся список для выбора инстанса/раздела с другим продуктом, работающий с мультидоменной сборкой.

См. докпортал edna - https://docs-pulse.edna.ru/

# Как внедрить

Рассказываю на докладе. Если доклад не состоится и/или возникли сложности — пишете мне в tg @DmMaze или заводите issue.
